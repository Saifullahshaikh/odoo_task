# Odoo Portal Timesheet Customization

Custom Odoo development task that enables portal users to submit timesheet entries through the customer portal.

## Objective

Extend the standard Odoo portal experience so authorized portal users can create timesheet entries without requiring backend access.

## Functional Scope

- Portal-accessible timesheet entry flow
- User-friendly form for submitting work details
- Validation before creating timesheet records
- Controlled access for portal users
- Integration with Odoo's existing timesheet models

## Technical Focus

- Odoo controllers and portal routes
- QWeb portal templates
- Odoo ORM
- Access rights and security considerations
- Form validation and record creation

## Use Case

This customization is useful when external users, contractors, or client-side users need to submit timesheet information while remaining restricted to the Odoo portal.

## Notes

The repository demonstrates a focused Odoo customization task rather than a full standalone Odoo deployment.
